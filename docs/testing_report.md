# 测试报告

## 1. 测试环境
- **操作系统**: macOS
- **Docker 版本**: Desktop 最新版
- **构建命令**: `docker compose up -d --build`

## 2. 功能测试用例
| 测试项 | 预期结果 | 测试状态 |
| :--- | :--- | :--- |
| 基础页面展示 | 进入 8080 端口，看到仪表盘界面 | 通过 |
| 数据库连通性 | 页面能加载出初始的 5 个服务条目 | 通过 |
| 服务启动操作 | 点击“启动”，状态变为“运行中”，图标开始闪烁 | 通过 |
| 服务停止操作 | 点击“停止”，状态变为“已停止”，操作按钮变色 | 通过 |
| 审计日志生成 | 操作后，查看 `./LOG/app.log` 存在对应操作记录 | 通过 |
| 日志持久化 | 重启容器后，之前的日志文件依然存在 | 通过 |

## 3. 性能表现
- 容器启动时间：约 5-10 秒（MySQL 初始化可能稍慢）。
- 页面加载时间：基础资源加载 < 1秒。
- API 响应时间：本地环境下 < 10ms。

## 4. 结论
项目功能符合设计需求，容器化配置完善，能够稳定运行。
