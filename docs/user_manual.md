# 用户手册

## 1. 快速开始
1.  **环境准备**: 确保您的计算机已安装 Docker 和 Docker Compose。
2.  **获取项目**: 进入项目根目录。
3.  **启动系统**:
    ```bash
    docker compose up -d
    ```
4.  **访问页面**: 打开浏览器访问 `http://localhost:8080`。

## 2. 界面操作说明
- **服务看板**: 展示了系统检测到的所有服务。
- **状态标签**: “运行中”表示服务正常，“已停止”表示服务处于关闭状态，“异常”表示服务出错。
- **操作按钮**:
  - 点击 **[启动]**：激活对应服务条目。
  - 点击 **[停止]**：禁用对应服务条目（颜色将变为灰色）。
- **刷新按钮**: 页面右上角可手动拉取最新状态。

### 2.1 自动刷新
- 页面默认每 **10 秒**自动拉取一次服务状态，采用**原地更新**：只刷新状态文字与按钮，
  不会重建卡片，因此您展开的“详情/日志”面板、页面滚动位置都不会被打断。
- **配置刷新频率**：右上角“自动刷新”下拉框可选择 `暂停 / 5 秒 / 10 秒 / 30 秒 / 1 分钟 / 5 分钟`。
  - 本地机器性能较差时，建议选择 **1 分钟**、**5 分钟**或直接**暂停**。
  - 选择会自动保存在浏览器中（localStorage），下次打开仍生效。
  - 切换到其他浏览器标签页时轮询自动暂停，回到本页时立即拉取一次并恢复计时。
- **拉取失败的处理**：网络或接口异常时，页面**保留现有列表和“最近更新”时间**不清空，
  顶部状态变为琥珀色提示“拉取失败，已保留最近状态”，并在下一个间隔自动重试。
  仅首次打开页面就失败时，才会显示整页错误信息和“重试”按钮。

## 3. 查看日志
- **页面内查看**：点击服务卡片上的 **[查看日志]** 可就地展开该服务最近 20 条日志，
  点击“刷新日志”可手动重新拉取。自动刷新服务列表**不会**覆盖您正在查看的日志内容。
- 您也可以在项目的 `LOG` 文件夹下查看日志记录：
  - `app.log`: 记录了所有的用户操作（谁在什么时候启动/停止了什么服务）。
  - `nginx/access.log`: 记录了 Web 访问详情。

## 4. 常见问题 (FAQ)
- **Q: 页面显示“数据库连接失败”？**
  - A: 首次启动时，MySQL 容器可能还没完全就绪。自动刷新会持续重试，等待约 10-20 秒后即可正常显示，也可手动点击“刷新列表”。
- **Q: 自动刷新影响本地机器性能怎么办？**
  - A: 在右上角把“自动刷新”改为“1 分钟”、“5 分钟”或“暂停”即可；切换到后台标签页时轮询也会自动暂停。
- **Q: 端口 8080 被占用了怎么办？**
  - A: 修改 `docker-compose.yml` 中的 `ports: ["8080:80"]` 为其他未占用端口，如 `["9090:80"]`。
