# 用户手册

## 1. 快速开始
1.  **环境准备**: 确保您的计算机已安装 Docker 和 Docker Compose。
2.  **获取项目**: 进入项目根目录。
3.  **启动系统**:
    ```bash
    docker compose up -d
    ```
4.  **访问页面**: 打开浏览器访问 `http://localhost:8080`。

## 2. 界面操作说明
- **服务看板**: 展示了系统检测到的所有服务。
- **状态标签**: “运行中”表示服务正常，“已停止”表示服务处于关闭状态。
- **操作按钮**:
  - 点击 **[启动]**：激活对应服务条目。
  - 点击 **[停止]**：禁用对应服务条目（颜色将变为灰色）。
- **刷新按钮**: 页面右上角可手动拉取最新状态。

## 3. 查看日志
您可以随时在项目的 `LOG` 文件夹下查看日志记录：
- `app.log`: 记录了所有的用户操作（谁在什么时候启动/停止了什么服务）。
- `nginx/access.log`: 记录了 Web 访问详情。

## 4. 常见问题 (FAQ)
- **Q: 页面显示“数据库连接失败”？**
  - A: 首次启动时，MySQL 容器可能还没完全就绪。请等待约 10-20 秒后刷新页面即可。
- **Q: 端口 8080 被占用了怎么办？**
  - A: 修改 `docker-compose.yml` 中的 `ports: ["8080:80"]` 为其他未占用端口，如 `["9090:80"]`。
