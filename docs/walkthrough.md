# 项目演示与说明 (Walkthrough)

## 核心功能展示
1.  **现代化看板**: 启动项目后，用户可以看到一个简洁的仪表盘，列出了 Nginx, MySQL, Redis 等基础服务。
2.  **状态实时切换**: 每个服务卡片右下角有操作按钮。点击“停止”会将运行中的服务变为停止状态，且图标动画消失。
3.  **多重日志追踪**:
    *   面板上的每一次点击都会记录在容器内的 `/var/log/app/app.log` 中。
    *   在宿主机的 `./LOG` 目录下可以直接查看到这些日志文件。

## 技术亮点
*   **100% 容器化**: 无需在宿主机安装 PHP 或 MySQL，执行 `docker compose up` 即可。
*   **持久化存储**: 即使删除容器，`data` 目录下的数据库记录和 `LOG` 下的运行日志也会保留。
*   **响应式设计**: 面板完美适配移动端和桌面端浏览器。

## 验证流程
1.  **Step 1**: 运行 `docker compose up -d`。
2.  **Step 2**: 浏览器打开 `http://localhost:8080`。
3.  **Step 3**: 尝试切换一个服务的状态，观察页面 UI 变化。
4.  **Step 4**: 查看本地 `LOG/app.log`，确认操作已成功记录。
